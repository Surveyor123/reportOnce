# reportOnce

reportOnceは、同じグループ内のすべてのオブジェクトに対して、NVDAがオブジェクトの位置情報(たとえば「3/10」)を繰り返し読み上げないようにする小さなNVDAアドオンです。

### 使い方

1. NVDAの設定を開き、「オブジェクトの表示」カテゴリに移動します。
2. 「オブジェクトの位置情報を報告」がオンになっていることを確認してください。新しいチェックボックスは、オンのときにのみ表示されます。
3. 「位置情報を1回だけ報告する」をオンにします。

有効にすると、NVDAはオブジェクトに移動したときに位置情報を報告し、同じ親、役割、レベルを持つオブジェクト間を移動している間は繰り返しません。別のグループに入ったとき、またはグループに戻ったときには、再び報告されます。

チェックボックスがオフの場合、NVDAは従来どおりに動作します。

### 注意事項

- NVDA+Tabを押すと、常にすべての情報が報告されます。
- 現在は、フォーカスの変更とオブジェクトナビゲーションが対象です。ブラウズモードには影響しません。

### 動作要件

NVDA 2025.1以降。
