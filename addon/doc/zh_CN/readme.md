# reportOnce

reportOnce 是一个小型 NVDA 插件,可以避免 NVDA 为同一组中的每个对象重复报告对象位置信息(例如“3/10”)。

### 用法

1. 打开 NVDA 设置,进入“对象表示”类别。
2. 确保已勾选“报告对象位置信息”。仅在勾选时才会显示新的复选框。
3. 勾选“仅报告一次位置信息”。

启用后,NVDA 会在您移动到某个对象时报告位置信息,而在具有相同父对象、角色和层级的对象之间移动时不会重复报告。进入不同的组或返回某个组时,会再次报告。

未勾选该复选框时,NVDA 的行为与之前完全相同。

### 注意事项

- 按 NVDA+Tab 始终会报告完整信息。
- 目前涵盖焦点变化和对象导航。浏览模式不受影响。

### 要求

NVDA 2025.1 或更高版本。
