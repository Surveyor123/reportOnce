# reportOnce

reportOnce to niewielki dodatek do NVDA, który zapobiega powtarzaniu przez NVDA informacji o pozycji obiektu (na przykład „3 z 10”) dla każdego obiektu w tej samej grupie.

### Użycie

1. Otwórz ustawienia NVDA i przejdź do kategorii Prezentacja obiektów.
2. Upewnij się, że opcja „Zgłaszaj informacje o pozycji obiektu” jest zaznaczona. Nowe pole wyboru pojawia się tylko wtedy.
3. Zaznacz opcję „Zgłaszaj informacje o pozycji tylko raz”.

Po włączeniu NVDA zgłasza informacje o pozycji po przejściu do obiektu i nie powtarza ich podczas poruszania się między obiektami o tym samym rodzicu, roli i poziomie. Informacje są zgłaszane ponownie po wejściu do innej grupy lub powrocie do poprzedniej.

Gdy pole wyboru nie jest zaznaczone, NVDA działa dokładnie tak jak wcześniej.

### Uwagi

- Naciśnięcie NVDA+Tab zawsze zgłasza pełne informacje.
- Obecnie obejmuje zmiany fokusu i nawigację obiektową. Tryb przeglądania nie jest objęty.

### Wymagania

NVDA 2025.1 lub nowszy.
